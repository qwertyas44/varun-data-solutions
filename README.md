# Varun Data Solutions website

A responsive static website for Python-based CSV/Excel cleaning and reporting.

## Files
- `index.html` — page content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and email-draft contact form

## Preview locally
Open `index.html` in a browser. No build tools or paid software required.

## Publish publicly for free with GitHub Pages
1. Create a new public GitHub repository named `varun-data-solutions` (or another name you prefer).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/(root)`, and save.
6. Wait a few minutes. GitHub will show the public URL, usually `https://YOUR-USERNAME.github.io/varun-data-solutions/`.
